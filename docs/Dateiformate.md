# Dateiformate

## Layoutdatei
Empfohlene Dateiendung:
- `.dgslayout.json`

Inhalt:
- Metadaten
- Canvas-Einstellungen
- Kameras
- Blöcke
- Plätze
- Teilnehmerliste

## Settings-Datei
Lokale App-Datei:
- letzter Layoutpfad
- Standard-Speicherordner
- optionale Kamera-Defaults

## Speichersicherheit
Beim Speichern:
1. temporäre Datei schreiben
2. alte Datei sichern
3. neue Datei atomar ersetzen
