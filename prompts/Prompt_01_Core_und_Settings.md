# Prompt 1/6

Untersuche zuerst den Istzustand dieses Neuprojekts und führe danach ausschließlich den nächsten kleinen, buildfähigen Block aus.

Ziel dieses Blocks:
- Shared Core fachlich vervollständigen
- Settings-Datei-Service und Layout-Datei-Service an die App anbinden
- Startlogik vorbereiten, damit beim App-Start der zuletzt konfigurierte Layoutpfad geladen werden kann

Anforderungen:
1. Bestehende Projektstruktur beibehalten.
2. Minimal-invasiv arbeiten.
3. Keine UI-Überladung.
4. Noch keinen echten Layout-Designer umsetzen.
5. Noch keine reale Kamera-Kommunikation einbauen.
6. Die Beispiel-Dateien nur als Referenz nutzen.
7. Eine klare Trennung zwischen lokalen App-Settings und Layoutdatei einhalten.
8. Logging und Fehlertexte für fehlende oder ungültige Layoutdateien vorsehen.
9. Arbeitsplan und beide Logdateien nach Abschluss aktualisieren.

Validierung:
- Projektstand prüfen
- geänderte Dateien kurz benennen
- fachliche Änderungen kurz benennen
- offene Punkte kurz nennen

Git-Abschluss:
- Danach alle Änderungen git adden,
- einen sinnvollen Commit erstellen,
- und anschließend auf den aktuellen Remote-Branch pushen.
